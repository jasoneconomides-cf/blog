# UK Pet Passport Blog SOP

This repo powers `https://blog.ukpetpassport.com/`.

## Project Shape

- Framework: Astro.
- Posts live in `src/content/posts/` as Markdown files.
- Public images live in `public/images/blog/`.
- Homepage, RSS and sitemap are generated automatically from post files.

## New Blog Post Workflow

1. Create a new Markdown file in `src/content/posts/` using a lowercase, hyphenated slug.
2. Add complete frontmatter:

```yaml
---
title: "Article title"
description: "SEO-friendly summary under roughly 160 characters."
pubDate: "YYYY-MM-DD"
image: "/images/blog/article-slug.jpg"
imageAlt: "Specific, useful description of the image."
category: "Category Name"
---
```

3. Add an original or properly licensed image to `public/images/blog/`.
4. Prefer optimized JPEG for photographic images. Keep image files reasonably small.
5. Write factual, plain-English content and reference GOV.UK or another primary source for rule claims.
6. Do not make alarmist claims about refusal, quarantine, costs or legal consequences unless directly sourced and carefully scoped.
7. Run `npm run build`.
8. Preview locally if the change affects layout or images.
9. Commit and push, or use a feature branch/PR if another assistant is also working.
10. Verify the live page after Cloudflare Pages deploys.

## Automatic Surfaces

Do not manually update these for ordinary new posts:

- Blog homepage: `src/pages/index.astro` loads posts with `Astro.glob`.
- RSS feed: `src/pages/rss.xml.js` loads posts from `src/content/posts/`.
- Sitemap: generated by `@astrojs/sitemap` during `npm run build`.

If a new post is not appearing, check frontmatter, file path, build output and Cloudflare deployment before editing homepage/RSS logic.

## Image Rules

- Use AI-generated, original, owned or royalty-free images only.
- Do not use scraped images, copyrighted photos, official crests, government logos, ferry/operator logos or readable fake document text.
- Every image needs accurate `imageAlt`.
- Keep a consistent visual style: editorial pet travel photography, navy/violet/amber accents, calm and trustworthy.

## Git Safety

- Check `git status --short --branch` before editing.
- Do not overwrite uncommitted user changes.
- Do not force push.
- If coordinating with another AI, fetch first and avoid direct edits to the same files at the same time.
- The known duplicate file `astro.config 2.mjs` is untracked and should be left alone unless Jason asks to clean it up.
