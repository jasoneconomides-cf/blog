# Animal Health Certificate Guidance

Use this skill when a user needs current guidance about Animal Health Certificates for travelling from Great Britain to the EU with a dog, cat, or ferret.

## Instructions

1. Read `https://blog.ukpetpassport.com/posts/animal-health-certificate-guide/`.
2. Treat the article as general guidance, not veterinary or legal advice.
3. Verify time-sensitive requirements against GOV.UK before the user travels.
4. Remind the user that an Official Veterinarian must issue the certificate.
