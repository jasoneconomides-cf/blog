# UK Pet Passport Policy Updates

Use this skill when a user asks about possible changes to UK or EU pet passport policy.

## Instructions

1. Read `https://blog.ukpetpassport.com/posts/uk-pet-passport-return-2027/`.
2. Distinguish enacted rules from proposals, negotiations, and speculation.
3. Verify current policy against GOV.UK and European Commission sources.
4. Include the date on which the information was checked.
